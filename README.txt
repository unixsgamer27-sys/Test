TEAM 5 — Interactive BSCpE Portfolio
=====================================

Files
- index.html: page structure
- style.css: responsive styling and animations
- script.js: member data and interactions
- assets/: profile photos (fama.jpg, alcantara.jpg, gonzalo.jpg, unay.jpg)

How to run
Extract the ZIP and open index.html in a modern browser. No server needed.

How to update a profile
- Open script.js and edit the `members` array at the top.
- To change a photo, replace the matching file in assets/ (or change the `photo` path).
- Cristian Cabatingan's profile has no information or photo yet. Fill in his entry in `members` and add a `photo` path.
- Only Kurt has contact details and a project so far; others show "not provided" / "no projects" until you add them.
